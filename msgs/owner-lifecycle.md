# 屋主消息 · 季度复盘、续约、新屋主、邻居

> 屋主模板为中文。屋主需要英文时，Claude 按同样内容写成英文。

使用屋主 / 潜在屋主习惯的语言。事实和数字只能来自脚本。

## C. 季度复盘
### C1. 邀约
```
主题：[房源昵称] 第 [n] 季度复盘 —— 约 30 分钟？

[屋主称呼]，您好：

您的第 [n] 季度复盘已准备好。核心结论：屋主净收入 $[金额]，比去年第 [n] 季度 [增长 / 下降] [x]%。我想和您一起过一遍，并商定下季度的三项决定。

[选项 1] 或 [选项 2] 您哪个时间方便通话 30 分钟？复盘报告见附件，您可以提前看看。

祝好，
[屋主消息署名]
```

## J. 新屋主提案跟进序列
### J1. 第 0 天 —— 提案
```
主题：[地址 / 房源] 收益预测

[潜在屋主称呼]，您好：

感谢您带我们看了 [房源]。附件是我们的收益预测，基于 [n] 套可比房源以及 [城市] 现行的法规。

简而言之：我们预计作为 [短租 / 中租 / 混合模式]，首 12 个月屋主净收入为 $[保守] – $[预期]，而长租约为 $[金额]。报告列出了所有假设以及主要风险：[风险]。

有任何问题都欢迎随时问我。

祝好，
[屋主消息署名]
```
### J2. 第 3 天 —— 一个有用的洞察
```
主题：关于 [房源] 的一个想法

[潜在屋主称呼]，您好：

在完成您的分析时，我注意到一点：[具体、有用的洞察 —— “附近表现最好的三套房源都主打独立办公区，您的第二间卧室花大约 $650 就能做到”]。

无论您最终如何决定，希望这对您有帮助。

[屋主消息署名]
```
### J3. 第 10 天 —— 解答顾虑
```
主题：关于 [话题] 的问题

[潜在屋主称呼]，您好：

很多屋主在做决定前都会问到 [顾虑 —— “房屋损耗” / “费用” / “法规”]，以下是我们的处理方式：[两三句事实陈述]。[佐证：类似房源的匿名化成果（如有且获准使用）。]

需要通个 15 分钟的电话吗？

[屋主消息署名]
```
### J4. 第 21 天 —— 最后一次跟进
```
主题：您的资料还需要我继续保留吗？

[潜在屋主称呼]，您好：

不想占满您的收件箱，这是我近期最后一次跟进。如果现在时机不合适，完全没关系 —— 如果您希望我在今年晚些时候更新一下数据，告诉我就好。

祝好，
[屋主消息署名]
```

[屋主消息署名]
