# 屋主消息 · 日常（月度、维修、问题）

> 屋主模板为中文。屋主需要英文时，Claude 按同样内容写成英文。

语气冷静、透明，数字先行，以解决方案为导向。使用屋主习惯的语言（房源卡上没有写明时，先问用户）。数字必须与脚本输出一致。不用表情符号。

## A. 月度报告 + 账单（invoice）邮件（模式 A）
*月度结算后发送，附上屋主报告和账单（invoice）。*

```
主题：[月份] [房源昵称] 月度报告 + 账单（invoice）[账单编号]

[屋主称呼]，您好：

附件是 [房源昵称] 的 [月份] 月度报告。本月入住产生的收入，Airbnb 已向您支付 $[屋主收入]（已扣除 Airbnb 服务费）。

本月概况：
• 可订 [n] 晚中已订出 [n] 晚（入住率 [入住率]%），平均房价 $[平均房价]
• [最主要的影响因素，一句话]
• [一项亮点 —— 例如“新增两条五星评价，都提到了花园”]
• [一项正在改进的事项 —— 例如“还有三个工作日晚上空着，已调价争取订满”]

附件是我的账单（invoice）[账单编号]，金额 $[合计]（管理费 $[x]，清洁 [n] 次 × $[y]，代垫费用 $[z]，附收据）。付款截止日 [截止日期]。[设置中的付款方式。]

展望下月：[下个月] 目前已订出 [n] 晚。

如需逐项说明，随时告诉我。

祝好，
[屋主消息署名]
```

## B. 月中更新
*可选；建议用于新屋主或比较焦虑的屋主。每月 15 日前发送。*

```
主题：[房源昵称] —— [月份] 月中更新

[屋主称呼]，您好：

[月份] 已过半，简单向您汇报一下。目前已订出 [n] 晚（入住率 [入住率]%），房租收入 $[本月至今收入] —— [高于 / 持平于 / 低于] 去年同期（$[去年同期]）。

[屋主需要知道的问题或维修，包括费用和进展 —— 或写“本月至今没有维修或其他问题。”]

本月剩余时间，我们会 [一项行动：“把剩下三个空着的工作日晚上的最短入住改为一晚”]。月度结算后，我会发送完整报告和账单（invoice）。

祝好，
[屋主消息署名]
```

## D. 维修审批请求
*任何超出屋主预批额度（settings.md）的工单都要用这条。紧急情况按 §L 处理 —— 先行动，尽快告知屋主。*

```
主题：请于 [星期、时间] 前审批：[房源昵称] [维修项目] —— $[预估金额]

[屋主称呼]，您好：

[一句话说明发生了什么：“周六晚上客人反映热水浴缸不加热。”] 我们的供应商诊断原因为 [原因]（照片见附件）。

建议的修复方案：[维修范围]
报价：$[金额]，来自 [供应商] [如有两份报价：以及 $[金额]，来自 [供应商 2]]
推荐理由：[理由 —— 例如“使用原厂配件，保修 2 年；下一位客人周三入住，预订时部分是冲着热水浴缸来的”]
如果暂缓：[后果，附数字 —— “很可能需要补偿客人，并危及 4.9 的评分”]

能否在 [星期、时间] 前回复“同意”，以便我们今天就订购配件？我们会严格控制在报价范围内，如有任何变动会先致电您。

祝好，
[屋主消息署名]
```

## E. 客人造成损坏或发生事故
```
主题：[房源昵称] —— [日期] 入住后发现损坏，以及我们的处理方式

[屋主称呼]，您好：

我希望您第一时间从我们这里得知此事。[日期] 的入住结束后，我们的团队发现 [具体损坏]。照片和检查报告见附件；在那次入住前的检查中，房屋状况良好。

我们已采取的措施：
• [即时处理 —— 例如“在下一位客人抵达前更换了碎裂的玻璃桌面”]
• 已于 [日期] 通过 [渠道] 的付款请求向客人索赔 $[金额]
• [如需要] 将在 [日期] 前通过 [渠道] 的房东损坏保障计划提交索赔，在其索赔时限内

目前状态：[等待客人回复 / 索赔已提交 / 已赔付]。追回的任何款项都会以抵扣项的形式出现在您的对账单上，用于抵扣 $[费用] 的维修费用。结案后我们会及时告知您。

祝好，
[屋主消息署名]
```

```
[屋主称呼]，您好：

[日期] 那次入住的客人今天发布了一条 [n] 星评价，提到了 [具体问题]。

背景：[事实 —— 例如“清洁工漏清了淋浴下水口；客人第二天告诉我们后，我们在两小时内重新做了清洁”]。

我们的改进：[预防措施 —— 例如“未来 30 天，每次换房清洁都对浴室增加一轮照片复核”]。我们已公开回复，表达感谢并说明了改进措施；目前总评分为 [评分]（共 [数量] 条评价）。

祝好，
[屋主消息署名]
```

## G. 收入偏低的月份
*用数据解释。绝不归咎于屋主，也绝不在没有数字支撑的情况下归咎于“市场”。*

```
主题：[房源昵称] [月份] 业绩 —— 原因分析与我们的计划

[屋主称呼]，您好：

[月份] 的结果没有达到我们共同的预期：屋主净收入 $[金额]，比去年 [月份] 下降 [x]%。

主要原因：
• [原因 1，附数字 —— “市场需求：10 套可比房源的入住率从 74% 降到 61%”]
• [原因 2 —— “因地板维修封锁了 8 晚”]
• [表现稳住的部分 —— “我们的平均房价仍比可比房源高 3%”]

[下个月] 的计划：
1. [行动 —— “未来 30 天工作日价格下调 8%，最短入住改为一晚”]
2. [行动 —— “翻新后厨房的新照片于 [日期] 前上线”]
3. [行动 —— “从一月起开放按月入住”]

[下个月] 目前已订：[n] 晚，$[收入]（[与去年相比]）。我会在 15 日向您更新进展。

祝好，
[屋主消息署名]
```

## H. 屋主封锁日期 / 屋主自住
```
主题：您在 [房源昵称] 的自住，[日期] —— 已确认

[屋主称呼]，您好：

您的日期 [入住日] – [退房日] 已封锁。[如为旺季：“供您参考：这几晚目前定价约为每晚 $[x]，因此封锁这些日期大约相当于放弃 $[合计] 的潜在房租收入。”]

按管理协议约定，屋主自住清洁费 $[金额] 将计入您 [月份] 的对账单。房屋将于 [时间] 起准备就绪；您的个人门锁密码会在前一天通过门锁 app 发送。

有什么需要我们提前准备，或者希望保持原样的吗？

祝好，
[屋主消息署名]
```

## L. 房屋发生紧急情况
*先行动（先人员，后财产）。尽快告知屋主 —— 最迟当天。*

```
主题：紧急：[房源昵称] 发生 [事件] —— 所有人均安全

[屋主称呼]，您好：

[先说安全情况：“所有人均安全。”] 今天 [时间]，[发生了什么，一两句话]。

我们已采取的措施：
• [行动及时间 —— “06:40 关闭了总水阀”]
• [行动 —— “07:30 紧急水管工到场，漏水已止住”]
• [客人安置 —— “已将客人转移到 [房源]，不产生您的任何费用”]

下一步：[干燥 / 维修 / 保险]，预计费用 $[区间]，[时间安排]。[如可能涉及保险：“建议您今天就通知您的保险公司 —— 我们可以提供照片和发票。”]

我会在 [时间] 前再次向您更新。有任何问题随时致电我：[电话号码]。

[屋主消息署名]
```
