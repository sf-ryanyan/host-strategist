# 供应商与清洁工消息

> 消息正文保持英文（发给客人/清洁工/供应商）；说明为中文。

用英文写，简短、信息完整。供应商只能来自用户的 vendors.csv 或由用户提供 — 绝不编造。不写密码，统一写 "time-limited code sent via lock app"（限时密码通过门锁 app 发送）。绝不向供应商透露客人姓名或任何客人信息。

## V1. 紧急派单（严重级别 1）
*先打电话，再发这条作为书面确认。*

```
EMERGENCY — [issue] — [property code] — [WO ID]

Address: [street, unit, city]
Situation: [one line — "active leak under kitchen sink, water main is off"]
Guest in residence: [yes — please knock, then text on arrival / no — vacant]
Access: time-limited door code sent by lock app · or meet [on-call name] on site
On-site contact: [name] [phone]
Authority: stop the damage and make safe up to $[cap]; call before any further work
Parking: [instructions]

Please reply with your ETA. Before/after photos and invoice to [email] with [WO ID].
```

## V2. 加急派单（严重级别 2，当天处理）
```
URGENT TODAY — [issue] — [property code] — [WO ID]

Address: [street, unit, city]
Problem: [description] · photos attached
Window: [date] [start]–[end] [time zone] (next guest arrives [time])
Occupancy: [guest in residence / vacant]
Access: time-limited code by lock app, valid [window]
On-site contact: [name] [phone]
Budget cap: $[x] — call before exceeding
Parking: [instructions]

Please confirm you can make the window. Completion photos + invoice to [email], reference [property code] / [WO ID].
```

## V3. 常规工单（严重级别 3–4）
```
New job — [property code] — [WO ID]

Address: [street, unit, city]
Scope: [task list] · photos attached
Preferred dates: [vacant dates] between [times]
Access: time-limited code by lock app for your booked window
Budget cap: $[x] — call before exceeding
Notes: [materials on site / owner preferences / HOA rules for contractors]

Please reply with your available slot and quote if different. Invoice with [WO ID].
```

## V4. 询价（超出屋主额度的工程需两份报价）
```
Quote request — [property code] — [job]

We'd like a written quote for: [scope], at [address].
Photos and measurements attached. The home is [vacant on dates / occupied — site visit by appointment].
Please include: parts and labor separately, warranty, earliest start date, and your current license and insurance certificate if not already on file.
Quote needed by: [date]
```

## V5. 确认时间安排
```
Confirmed: [vendor] — [property code] — [date] [start]–[end] [time zone]
Scope: [one line] · Budget cap $[x]
Your access code will arrive by the lock app 30 minutes before the window.
On-site contact: [name] [phone]. Thank you!
```

## V6. 完工核查
```
Thanks for today's work at [property code] ([WO ID]). Could you send:
• After-photos of [area]
• Any parts replaced (model/serial if relevant)
• Warranty terms
• Invoice referencing [WO ID]
Anything we should watch or schedule next?
```

## V7. 账单（invoice）疑问
```
Hi [name], a question on invoice [number] for [WO ID]: the quote was $[quote] and the invoice is $[invoice]. Could you explain the difference ([line])? We can't pass costs above the quoted cap to the owner without prior approval. Thank you.
```

## V8. 保修返工
```
Warranty callback — [property code] — [WO ID]

The [part] you installed on [date] ([original WO ID]) is [problem — "dripping when closed"]. Photos attached. Please let us know your first available slot — the home is vacant on [dates]. As this is within the [warranty period] warranty, we expect no charge; please confirm.
```

## V9. 新供应商入职
```
Welcome to our vendor team, [name]. Before your first job, please send:
• Certificate of insurance (general liability; workers' comp if you have employees), with expiry date
• License number (if your trade requires one)
• W-9 (securely, via [secure upload link] — not by email)
• Rates: call-out, hourly, after-hours, and your service area
How we work: every job has a work-order ID, a budget cap and a time-limited door code. Invoices must reference the WO ID and include after-photos. Payment terms: [terms].
```

## 清洁工消息

### CL1. 每日排班（随保洁看板一起发出，前一天 16:00 前）
```
Tomorrow [day, date] — [cleaner name]
1. [Property code] [nickname] · out [time] → in [time] · [window] h · [risk]
   Notes: [pets / crib / deep clean / restock list]
2. [Property code] ...
Linens: pick up [n] bed sets and [n] towel sets from [location].
Inspection: [self + photos / inspector at time].
Codes come by the lock app for each window. Reply OK to confirm.
```

### CL2. 当天退房当天入住（高风险）
```
Same-day flip at [property code]: guests out [time], next guests in [time]. You and [second cleaner] are both scheduled. Linens are pre-staged at [location]. Please send the "cleaned" photo set by [time] so we can inspect. Call [coordinator] straight away if anything will make you late.
```

### CL3. 带宠物入住后的清洁流程
```
Pets stayed at [property code]: extra hair removal on sofas, rugs and bed skirts; lint-roll upholstery; check the yard and pick up waste; enzyme spray on any marks; wash pet bowls and blankets if provided. Photo of each sofa and rug please.
```

### CL4. 要求返工（验收不合格后）
```
Hi [name], the inspection at [property code] found [n] items below standard: [list]. Photos attached. The next guests arrive at [time] — could you return by [time] to fix these? Thank you — this one matters for the guest's first impression.
```

### CL5. 质量辅导（私下进行，针对反复出现的问题 — 不针对单次失误）
```
Hi [name], thank you for your work this month — [specific positive, e.g. "14 of 15 turnovers on time"]. One thing to focus on: [pattern — "shower drains were flagged at 3 inspections"]. Could we meet at [property] on [date] for 15 minutes to go through the reference photos together? Thank you.
```

### CL6. 失物招领
```
Lost and found at [property code], [date]: [item description]. Please bag it with a note (date, room) and leave it at [office / location]. Don't contact the guest directly — we'll arrange return.
```
