# B · 新房源上线，逐步操作（深度）

目标：根据房源信息，产出一份完整的上线清单，以及用户要粘贴到 Airbnb 的每一段文字——按用户实际操作的顺序排列。Airbnb 的菜单会变；每一项都按其功能描述（“Availability → minimum nights（可订设置 → 最少入住晚数）”），并告诉用户如果名称不同，以当前界面为准。

同时阅读：`settings.md`、`ref/south-bay.md`（或用户自己的 `ref/market-*.md`）（许可证展示）和房源卡。如果提供了照片或巡检清单，就使用它们；绝不声称未经确认的设施。

## 给用户的输出（说明用用户的语言（settings.md 里设置，默认中文），房源文字用英文），按以下顺序

### 1. 上线前准备清单（勾选框，屋主 + 用户）
- [ ] 合法：登记/许可证已办或已申请（来自指令包 A），如房源需展示编号则准备好编号
- [ ] HOA 书面批准（如有 HOA） · 屋主保险允许短租
- [ ] 账户设置：由谁的 Airbnb 账户发布房源（模式 A → 通常用屋主的账户，用户以 **co-host（协同房东）** 身份加入并设置正确权限——在 Airbnb 上确认当前的 co-host 选项）；打款方式 = 屋主
- [ ] 智能锁（每次入住通过门锁 app 生成唯一密码） · 已披露的噪音/人数传感器（室内不装摄像头）
- [ ] 安全：烟雾 + 一氧化碳报警器已测试、灭火器、急救包、紧急信息卡
- [ ] Wi-Fi 已测试（记录 Mbps） · 温控器 · 电视/流媒体
- [ ] 每张床 3 套床品，每位客人 3 套毛巾 · 厨房基本用品 · 首批耗材（列出清单）
- [ ] 已雇清洁工 + 现场交接 + “就绪”状态参考照片 · 备用清洁工
- [ ] 照片：专业、横拍、明亮（拍摄清单见下）

### 2. 照片拍摄清单（按上传顺序，每张配一行说明）
主图（最好的房间或黄金时段的外观） · 客厅全景 · 厨房全景 + 细节 · 餐厅 · 每间卧室（展示床型） · 每间卫生间 · 工作区 · 户外 · 特色亮点 · 入口/自助入住 · 停车 · 洗衣 · 周边亮点。

### 3. Airbnb 房源——字段和可直接粘贴的文字
每项：字段 → 值/文字。在界面上核对当前字数限制；标题另给一个更短的备选。
- 物业类型、客人数、卧室、床（按房间）、卫生间
- 设施：只列已确认的；“如属实可添加”的单独列出
- **标题**：3 个选项（以卖点为先：差异点 + 类型 + 设施 + 位置）+ 一个短备选
- **描述**各部分：开头（适合谁 + 前 3 个理由） · 房源空间 · 客人可使用区域 · 其他注意事项（诚实披露：楼梯、路边停车、共用墙）
- 房屋守则：最多客人数、宠物、吸烟、派对/活动、安静时段、入住/退房时间、其他规则（简短、友好）
- 入住方式：自助入住、智能锁；说明文字中使用 `[DOOR CODE — send via lock app / Airbnb]`
- Wi-Fi 信息字段（网络名称；密码按用户的选择通过安全字段/消息发送）
- 指南：5–8 个已核实的周边地点（超市、咖啡、餐饮、公园、药店、急诊诊所）——只用你今天核实过的地点

### 4. 定价和可订设置（来自指令包 A 的竞品；展示推理过程）
工作日/周末基础价 · 新房源上线折扣（例如前 3–5 单打 10–15% 折扣，之后逐步上调） · 周租/月租折扣（与中租价值对比核查） · 清洁费 · 额外客人费（只有竞品收才收） · 最少/最多入住晚数 · 提前预订通知 · 准备时间 · 可订窗口 · 即时预订（通常开启，并设客人要求） · 取消政策（选择 + 理由）。

### 5. 自动（定时）消息——英文，可直接粘贴
预订确认 · 入住前 3 天（行程细节问题） · 入住前 1 天（入住说明，密码通过安全方式发送） · 入住当天（欢迎） · 入住次日早上（一切还好吗？） · 退房前一晚（简单的退房步骤） · 退房后（感谢 + 邀请评价）。简短、温暖，每条只讲一件事。

### 6. 上线检查
以客人身份预览房源 · 日历正确（屋主自用已屏蔽） · 选 3 个测试日期确认价格显示符合预期 · 如需则已展示登记编号 · co-host 通知已推送到用户手机 · 已关联清洁工日历。

### 7. 上线进度表（粘贴回来即可更新）
表格：步骤 · 负责人（用户 / 屋主 / 供应商） · 截止日期 · 状态（未开始 / 进行中 / 已完成 / 受阻） · 备注——第 1–6 部分每项一行。用户修改后粘贴回来；你更新表格并先列出受阻项。
另外可提供（一次性）：房源卡的 FAQ + 增值服务（`packs/c2-faq-upsell.md`）、定价规则文件（`packs/k-pricing-setup.md` §Setup）、合规记录行（`packs/n-compliance.md`），以及手机巡检页面（`scripts/tools.py inspection`）。

### 8. 前 30 天计划
快速回复（约 1 小时内） · 关注最初几条评价，当天解决每条意见 · 每周根据预订进度（book pace）调整价格 · 获得 3 个五星评价后，向市场价上调 · 第 30 天向屋主汇报。

## 自查
- [ ] 每项设施和事实都可追溯到房源卡/照片/用户 · 没有编造。
- [ ] 任何文字中都没有密码或口令。
- [ ] 价格依据竞品解释；已说明上线折扣及结束日期。
- [ ] 需要用户在界面上核实的项目（字数限制、co-host 权限、登记字段）已标注 需核实。
