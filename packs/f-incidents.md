# F · 紧急情况、索赔、派对、纠纷（深度）

**同时阅读：** `packs/c-guests.md`（消息语气） · `settings.md`（限额、联系人、到场时限目标） · 如需维修或开工单，读 `packs/e-cleaning.md`。

目标：先保护人员，再保护房屋，然后是钱和用户的账户记录。给用户明确的步骤、需保留的证据、消息以及 Airbnb 处理路径。Airbnb 的流程、期限和保障范围会变：**每次都查阅当前的 Airbnb Help Center（帮助中心）页面**（AirCover for Hosts、damage claims / Resolution Center、派对和活动政策、勒索 / 评价政策、报告安全问题），并注明来源和日期。这不是法律建议——当法律起决定作用时，写“请咨询律师或持牌专业人士”并说明原因。

## 0. 最初 60 秒（任何事件）
1. 有人身处危险吗？→ 客人拨打 **911**；如有必要用户也拨打。闻到燃气味 → 所有人撤离，在室外拨打 911 / 燃气公司。一氧化碳报警 → 所有人撤离，拨打 911。
2. 在安全的前提下阻止损失扩大（总水阀、电闸）。
3. 立即开始写**事件记录**（见下）——时间很重要。

## 事件记录（由用户保存；你根据用户的笔记填写）
```
事件记录 · [property] · 预订 [code] · 客人 [first name + initial]
时间 (PT) | 发生了什么 / 看到了什么 | 谁 | 采取的行动 | 证据文件
```
证据规则：带时间戳的照片/视频，远景 + 近景，与入住前照片同一角度；保留入住前的巡检/清洁工照片；Airbnb 消息截图（绝不把对话转到平台外）；噪音传感器曲线图；收据、报价、发票；清洁工的书面说明；如有报警，记录警方报告编号。每个事件存一个文件夹。

## 1. 损坏或额外清洁 → 索赔
1. 退房当天：照片/视频 + 清洁工说明 + 证明之前完好的入住前照片。
2. 获取维修/更换报价或收据（实事求是，不夸大；按 Airbnb 当前页面关于物品估价的说明执行）。
3. 查阅当天的 Airbnb Help Center，确认：如何向客人请款、**截止期限**、所需证据，以及 AirCover for Hosts 如何适用。把截止期限连同日期写进用户的待办。
4. 在 Airbnb 上给客人发消息（为用户起草）：事实、照片、金额，通过 Airbnb 的请款工具（request-money tool）发起。冷静、具体，除事实外不做指责。
5. 如果客人拒绝，或在 Airbnb 显示的期限内未回应 → 在同一请求中升级到 Airbnb 客服 / AirCover；附上证据清单。
6. 屋主更新（屋主的语言）：发生了什么、证据、索赔金额、进展、已修好的部分。追回的钱 → 在月报中注明。
交付物：证据清单（已勾选/缺失） · 客人消息 · Airbnb 客服消息 · 屋主更新 · 截止期限。

## 2. 派对、人数过多、违反规则、噪音
升级阶梯——每一步都要记录：
1. 传感器报警或邻居来电 → 约 10 分钟内在 Airbnb 上友好提醒（安静时段、最多客人数）。
2. 持续约 20–30 分钟 → 打电话 + 发一条措辞坚定的书面消息，引用对方已接受的房屋守则。
3. 仍在继续 / 明显是派对 / 超员 → 联系 Airbnb（按 Help Center 当前的安全 / 紧急支持热线）报告；询问能否依据派对政策取消该预订。只有两人同行才可到现场，绝不在夜间独自对峙。
4. 报警：针对安全威胁或暴力，或按当地噪音执法规定——不能仅因规则纠纷报警。
5. 事后：证据包、损坏/额外清洁索赔（第 1 部分）、陈述事实的评价、禁止其今后预订、给邻居的致歉便条（以用户名义，不含客人信息）、屋主更新。
绝不：断水断电、对仍在房内的客人换锁、移走其物品，或在室内录音/录像。

## 3. 客人拒不离开 / 超期入住 / 长期入住
先发消息 + 联系 Airbnb 客服。**不要**自行采取措施（换锁、移走物品、断水断电）。在加州，较长时间的入住可能产生租客权利——如果客人拒绝离开，或入住接近 30 晚，用户在采取行动前应先咨询律师或持牌专业人士。记录一切。

## 4. 纠纷
| 情况 | 做法 |
|---|---|
| 入住后要求退款 | 事实 + 照片；执行取消政策；只有确属房东方的问题才给善意补偿（按比例） |
| “与描述不符”投诉 | 把房源文字/照片与问题对照；快速解决，严重的话换房安置；如客人要求取消/退款，让 Airbnb 介入 |
| 威胁：“退款，否则给差评” | 不付钱，保持礼貌，截图，向 Airbnb 报告为可能的评价勒索（核实现行政策） |
| 客人在房内受伤 | 先救助（必要时拨打 911）；书面上不承认过错；只陈述事实；当天通知屋主和屋主的保险公司；用户应咨询律师或持牌专业人士 |
| 邻居 / 市政投诉 | 确认收到、为造成的影响道歉、解决根源、保留记录；按时回复市政部门 |
| 歧视指控 | 停下，只讲事实，立即上报 Airbnb，并请咨询律师或持牌专业人士 |

## 5. 房屋紧急情况（客人端步骤 + 用户的行动）
| 事件 | 客人 | 用户 |
|---|---|---|
| 漏水 | 如已教过就关闭水阀；移开贵重物品 | 水管工（严重程度 1）、水损照片、通知屋主 + 保险公司 |
| 停电 | 检查电闸（位置卡）；查看电力公司停电地图 | 如只是本户停电则叫电工；停电时间长则提供换房安置 |
| 无暖气（寒冷） / 无空调（酷热） | 温控器重置步骤 | 当天派供应商；提供风扇/取暖器；损失了使用时长则部分退款 |
| 被锁门外 / 门锁故障 | — | 通过门锁 app 远程开锁或发新密码；锁匠；在设置中的到场时限目标内到达现场（如为空，尽快到达并告知客人时间） |
| 火灾 / 燃气 / 一氧化碳 | 先撤离，拨打 911 | 911、屋主、保险公司、为客人换房安置 |

## 6. 屋主事件报告（屋主的语言）
先讲安全（“everyone is safe” / “所有人都安全”）→ 发生了什么（时间） → 我们做了什么 → 目前费用 / 预估 → 索赔进展 → 预防措施 → 下次更新时间。
