## 🧭 这是什么

**房东军师（host-strategist）** 是一个 Claude 技能（skill），专为**替屋主管理 Airbnb 短租房源的房东和管理人**设计，也适合管理自己房子的个人房东。

它覆盖一套托管房源的完整生命周期：

> **评估**房子 → **上线**房源 → **日常运营**（客人、日历、定价、清洁）→ **每月**给屋主出报告、开账单 → **每季度**复盘、续约

你用中文跟 Claude 说话，粘贴客人消息，或上传 Airbnb 导出的文件，它就会给出可以直接使用的结果：客人回复、价格计划、屋主月报、账单、清洁检查表、评估报告。

**适用的经营模式（模式 A）：** Airbnb 直接打款给屋主；管理人每月给屋主出报告，并开账单收取管理费、清洁费和经批准的维修费用。

> 📌 **许可提醒：** 个人房东管理自有房源（最多 3 套）可以免费使用；**替他人管理房源并收费需要商业授权**，见 [许可与商业授权](#️-许可与商业授权)。

## 🎯 解决哪些痛点

| 痛点 | 没有它 | 有了它 |
|---|---|---|
| **客人消息一天到晚回不完** | 每条都从头写；容易漏掉规定或答应错东西 | 几秒钟出一条可以直接粘贴的英文回复，并标出风险（派对迹象、平台外付款、以差评要挟） |
| **多平台重复订单** | 用眼睛对 Airbnb、VRBO、Booking.com 的日历 | 脚本把所有日历放在一起检查，发现重叠立即警告 |
| **定价靠感觉** | 忘了节假日和本地活动；空档夜卖不出去 | 90 天价格计划：内置美国联邦节假日、本地活动、空档和临近入住规则，只列出"需要在 Airbnb 修改的晚数" |
| **每月给屋主算账** | 在表格里折腾几个小时；跨月订单难分；清洁次数对不上 | 一条命令把 Airbnb CSV 变成按入住日期计算的月报、账单和 Google Sheets 台账 |
| **催款** | 不清楚谁付了谁没付 | 账单追踪显示已付 / 部分付款 / 未付 / 逾期，并对逾期发出警告 |
| **清洁质量** | 清洁工漏项，没有证据 | 换房清洁检查表 + 45 项手机验收页，实时打分 |
| **维修费漏收** | 维修忘了向屋主收费 | 工单记录；屋主承担的维修自动计入当月账单 |
| **拿新屋主** | 收入估得很粗 | 仔细的评估：先查法规，再算旺季 / 淡季收入、三种情景、短租 vs 中租 vs 长租 vs 混合模式、回本时间，并生成屋主一页摘要 |
| **损坏、派对、纠纷** | 压力大，容易错过索赔期限 | 分步骤的事件处理指引：证据、索赔步骤、消息草稿，平台规则每次都去官方核实 |
| **许可证、保险过期** | 发现时已经晚了 | 到期登记表，提前 60 天警告 |
| **工具太多、太贵** | 每件事一个付费软件 | 一个技能，复制粘贴就能用，不需要订阅 |

## ⚙️ 怎么运作

### 1. 复制、粘贴、上传 —— 不自动连接 Airbnb
你粘贴消息、上传导出文件（CSV、.ics）和自己的数据文件。Claude 负责分析、计算和起草。**所有内容都由你自己确认和发送。**

### 2. 智能分流 —— 只读这次需要的内容
主文件（`SKILL.md`）是一个很短的分流表。每次请求只打开**一个**小指令包。回复客人只读客人指令包，不会读账务或评估规则。

### 3. 三个级别

| 级别 | 用于 | 投入 |
|---|---|---|
| **精简** | 每天、每周的工作：客人回复、日历、每周定价、月报、清洁 | 简短、快速，不上网搜索，数字由脚本计算 |
| **定期** | 每月、每季度的工作：活动更新、竞品更新、房源健康、季度复盘 | 有固定上限（例如活动搜索 ≤ 5 次、竞品 ≤ 8 个） |
| **深度** | 一次性、高价值的工作：评估、上线、索赔、体检 | 质量优先，默认约 10 次网络搜索；超过之前会先问你 |

### 4. 数字全部由脚本计算
所有计算都在 Python 脚本里完成，结果准确、可重复。Claude 只运行脚本，不读源代码，因此很省 token。

### 5. 警告和提示
- ⚠️ **警告**：一定显示，每条一行（例如重复订单、账单逾期）。
- 💡 **提示**：可选建议，最多 3 条。你不说"要"，就不会多做任何事。

### 6. 语言
- 对你：**中文**（可在设置里改成英文）
- 对屋主：每次先问 **"中文还是英文？"**，房源卡写明了就不问
- 对客人、清洁工、供应商：**英文**

## 🚀 快速开始

### 第 1 步 —— 安装
1. 打开 [Releases 下载页](https://github.com/sf-ryanyan/host-strategist/releases/latest)，下载 **`host-strategist.zip`**。**不要解压。**
2. 在 Claude 里打开 **Customize → Skills → Upload**，选择这个 zip。
3. 确认技能已开启，名字显示为 **host-strategist**。
4. 升级时，用同样方法上传新版本 zip，会替换旧版本。

> 💡 请从 Releases 下载，不要用 GitHub 页面上的"Code → Download ZIP"。那个压缩包会多一层文件夹，上传到 Claude 可能出错。

### 第 2 步 —— 先试跑示例（可选，约 5 分钟）
`examples/` 文件夹里有一套**虚构的**示例数据（Airbnb 交易记录、日历、定价规则、工单、账单等）。上传一个示例文件，对 Claude 说"用示例数据做 10 月月报"，就能看到完整效果。详细步骤见 [examples/README.md](examples/README.md)。

### 第 3 步 —— 第一次设置（约 30 分钟）

| 要做的事 | 在哪里 | 为什么 |
|---|---|---|
| 填写 **settings.md**：你的名字或品牌、付款方式、维修审批额度、退款额度、Airbnb 收费模式、提前入住费用 | `settings.md` | 账单、退款判断、评估都会用到。空白处会显示"待确认" |
| 每套房做一张**房源卡**：屋主和语言、房屋规则、设备、清洁收费、管理费、供应商、许可证号码和到期日 | `ref/property-card.md`（模板） | 每次回复客人和做月报都要用。需要时粘贴到对话里 |
| 填写你所在城市的**市场资料** | 复制 `ref/market-template.md`（南湾示例见 `ref/south-bay.md`） | 评估和上线时查法规、找数据来源 |
| 设置每套房的**定价规则** | 对 Claude 说："帮我设置 [房源] 的定价规则" | 生成 `pricing_<CODE>.json`，每周重复使用 |
| 建一个**数据文件夹**（电脑或 Google Drive），把 `templates/` 里的模板复制进去 | `templates/` | Claude 不能在不同对话之间记住文件，需要你自己保存 |

**怎么修改 settings.md（两种方法，选一种）：**
- **方法 A（最简单）：** 不改技能本身。把填好的 `settings.md` 和房源卡放在你的数据文件夹里，需要时粘贴或上传到对话中。
- **方法 B（一次改好）：** 解压 `host-strategist.zip` → 用文本编辑器修改 `host-strategist/settings.md` → 把**整个 `host-strategist` 文件夹**重新压缩成 zip（压缩包里第一层必须是这个文件夹）→ 在 Customize → Skills 重新上传。

| 屋主月报 | "做 10 月月报" | Airbnb 交易记录 CSV（+ `workorders.csv`、上月 `_report.json`） | 中文摘要、屋主月报、账单、台账 |

| 评估房子 | "评估这套房能不能做 Airbnb" + 地址和情况 | 照片、屋主提供的信息 | 评估报告 + 屋主一页摘要 + 话术 |
| 新房源上线 | "新房源上线" | 房源卡 | 上线清单和追踪表 |
| 处理突发事件 | "客人开派对了" / "要索赔" | 照片、消息、时间线 | 处理步骤、证据清单、消息草稿 |
| 检查到期 | "检查许可证到期" | `compliance.csv` | 60 天内到期的警告 |

**每次回答的固定格式：**
1. 可以直接复制的草稿
2. ⚠️ 警告（如有）
3. **下一步**：1–3 个行动（确实有才写）
4. 💡 提示（可选，最多 3 条）

## 📅 每月月报流程

1. 从 Airbnb **下载**当月的 **Transaction history（交易记录）** CSV。
2. **开一个新对话**，说"做 [房源] 10 月月报"，上传 CSV、`workorders.csv` 和上个月的 `_report.json`。
3. **看中文摘要**，检查警告（例如订单重叠、打款对不上、未完成的紧急维修）。
4. 被问到"要生成屋主月报 PDF 和 invoice 吗？"时，回答要。
5. 打开月报和账单的 HTML 文件，在浏览器里**打印成 PDF**。
6. 连同起草好的邮件**发给屋主**。
7. **保存**新的 `_report.json` 和更新后的 `invoices_updated.csv`，并把台账 CSV 追加到你的 Google Sheet。

## 🗂 你需要保存的数据文件

模板在 `templates/` 里。把自己的副本放在一个文件夹，做哪项任务就上传哪个文件。脚本写出更新后的文件时，保存下来替换旧文件。

| 文件 | 内容 | 何时更新 |
|---|---|---|
| `pricing_<CODE>.json` | 每套房的定价规则：基础价、最低价、最高价、季节、节假日规则 | 设置一次，每周使用 |
| `events.csv` | 本地活动：日期、加价、最少入住晚数、来源、核实日期 | 每月活动更新 |
| `workorders.csv` | 每一次维修：状态、费用、谁承担、收据 | 每次维修 |
| `invoices.csv` | 屋主账单和收款 | 每次开账单和收款 |
| `compliance.csv` | 许可证、登记、保险、安全设备到期日期 | 有事项续期时 |
| `vendors.csv` | 清洁工和各工种，每个关键类别两家 | 供应商变动时 |
| `<CODE>_<YYYY-MM>_report.json` | 每月结果 | 每月；用于环比和季度复盘 |
| Google Sheet 台账 | 每月 `_ledger.csv` 的所有行 | 每月 |

> 数据文件的列名（第一行）保持英文，脚本按列名读取，请不要修改。

## 🧮 计算脚本

所有脚本都在 `scripts/` 里，默认输出中文。不带参数运行会显示用法。

| 脚本 | 作用 | 输出 |
|---|---|---|
| `calendar_check.py` | 读取 `.ics` 和订单 CSV；找重叠、空档和换房清洁；计算未来入住率 | `_calendar.json`、`_board.json`、`_dashboard.json` |
| `rate_plan.py` | 90 天价格计划：节假日、活动、空档、临近入住、最少入住晚数；和当前价格对比 | `_rates.csv` |
| `airbnb_month.py` | 用 Airbnb 交易记录算月度数字：按入住日期分摊房租、清洁次数、调整项、工单、打款核对、账单 | `_ledger.csv`、`_invoice.json`、`_report.json` |
| `ar.py` | 账单追踪：添加账单、记录收款、显示逾期 | `invoices_updated.csv` |
| `quarter.py` | 把月度结果合成季度复盘；同比去年 | `_quarter.json` |
| `str_model.py` | 评估测算：情景、管理费档位、成本、中租、长租、混合模式、回本、屋主摘要 | `_result.json`、`_owner_spec.json` |
| `tools.py` | `inspection`：手机验收页 · `expiry`：合规到期检查 | `.html` / 警告 |
| `render.py` | 把报告或账单数据生成简洁的一页 HTML（中文或英文） | `.html` |

**脚本使用的账务规则**
- **按入住日期计算**：房租按每个月的晚数分摊。
- 清洁费算在入住当月。**换房清洁次数** = 当月退房的订单数。
- 管理费基数默认是**净房租**：扣除 Airbnb 房东服务费后的房租，不含清洁费。也可以选总收入或实际打款。
- 屋主收入使用 Airbnb 自己的数字。Airbnb 代收的税款不算屋主收入。
- 数字从不为了好看而修改，有问题就解释清楚。

## 🔔 警告和提示

| 类型 | 显示方式 | 例子 |
|---|---|---|
| ⚠️ **警告** | 一定显示，每条一行，放在最前面 | 订单重叠 · 打款或账单对不上 · 账单逾期 · 许可证或保险已过期或 60 天内到期 · 未完成的紧急维修 · 本月还没结束 |
| 💡 **提示** | 可选，放在最后，最多 3 条 | "入住率低于 60%，要做定价检查吗？" · "收入比上月下降超过 15%，要分析原因吗？" · "活动表太久没更新，要更新吗？" |

对提示说"不要"或不理会，就什么都不会发生，同一个对话里也不会再提。

警告只针对你上传的文件。例如没有上传 `invoices.csv`，就不会有逾期警告。

**默认门槛**（可在 `settings.md` 修改，Claude 运行脚本时会把设置值传进去）：入住率目标 60% · 收入下降 15% · 到期窗口 60 天 · 验收合格 95%。

## 💡 省 token 的设计

重复的工作尽量省，高价值的工作才多花。

| 任务 | 读取的技能内容（约） |
|---|---|
| 回复客人 | 约 3,700 tokens（用模板时约 4,700） |
| 日历检查 | 约 3,200 tokens |
| 每周定价 | 约 3,000 tokens |
| 清洁 / 工单 | 约 3,800 tokens |
| 屋主月报 | 约 4,900 tokens |
| 评估 | 约 6,900 tokens + 网络搜索 |

> 以上为估算值，实际会因问题长短和上传的文件而不同。

**小建议**
- **一个任务开一个对话。** 对话越长，每一轮重复发送的历史越多，越贵。
- 回复客人、检查日历这类工作，可以用**更小、更快的模型**。
- 只上传这次任务需要的文件。
- 这份 README **不会**在技能运行时被读取，写多长都不花 token。

## 🚧 限制

- **不会实时连接** Airbnb、VRBO 或 Booking.com。需要你上传导出文件，再把回复复制回去。
- **对话之间没有记忆。** 数据文件需要你自己保存，下次再上传。
- **测试版：** CSV 和 `.ics` 读取程序按 Airbnb 的导出格式编写，已用虚构数据完整测试，但还没有覆盖所有真实账户的导出格式。第一次使用真实数据时请仔细核对；如果列名或日期格式不同，欢迎提交问题。
- 法规、税务、平台规则和费用会变。技能会去官方来源核实，或告诉你要核实什么，从不凭记忆陈述。
- 它只起草，从不发送。每条消息、每份文件都由你确认后发出。
